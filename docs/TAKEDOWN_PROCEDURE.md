# Takedown procedure (for admins)
Requests arrive at iistqps@gmail.com or as GitHub issues (public page /#/takedown says so).
1. Find the paper: Admin > Approved tab, search by course code.
2. Delete it (soft delete). For papers uploaded through the app this moves the PDF out of the public bucket (D19). Do this first, before checking the request.
3. If the request is for personal data or a confirmed owner claim: also open Admin > Trash and delete permanently.
4. Library papers (from_library = true) stay public after a soft delete (D14): use permanent delete.
5. Reply to the sender. If it was a public GitHub issue that contains personal details, ask GitHub to remove it or edit the issue yourself.
